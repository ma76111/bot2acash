# 🤖 Egypt Easy Cash Bot

بوت تيليجرام للربح من إنشاء حسابات Gmail مع نظام إحالة متقدم ونظام أمان محسّن.

## 📁 الملفات الأساسية

### ملفات الكود الرئيسية:
- `bot.js` - الملف الرئيسي للبوت (محمي أمنياً)
- `config.js` - إعدادات البوت والرسائل
- `database.js` - إدارة قاعدة البيانات (مع حماية من التكرار)
- `keyboards.js` - أزرار البوت (مع دعم إدارة الأدمنز)
- `cluster-bot.js` - تشغيل البوت بنظام Cluster للأداء العالي

### ملفات قاعدة البيانات:
- `bot_database.db` - قاعدة البيانات الرئيسية
- `bot_database.db-shm` - ملف SQLite مؤقت
- `bot_database.db-wal` - ملف SQLite للكتابة

### ملفات التشغيل:
- `start-bot.js` - سكريبت تشغيل البوت
- `start-bot.bat` - تشغيل البوت على Windows
- `start.sh` - تشغيل البوت على Linux
- `reset.bat` - إعادة تشغيل البوت

### سكريبتات مساعدة:
- `reset-bot-with-backup.js` - إعادة تعيين مع نسخة احتياطية (محدّث)

### ملفات التوثيق:
- `README.md` - هذا الملف
- `SECURITY-AUDIT-FINAL.md` - تقرير الفحص الأمني الشامل

### ملفات النظام:
- `package.json` - اعتمادات Node.js
- `package-lock.json` - قفل الإصدارات
- `.env.example` - مثال لملف البيئة
- `.gitignore` - ملفات Git المستبعدة

## 🚀 التشغيل

### Windows:
```bash
start-bot.bat
```

### Linux/Mac:
```bash
chmod +x start.sh
./start.sh
```

### يدوياً:
```bash
node bot.js
```

## ⚙️ الإعدادات

جميع الإعدادات في `config.js`:
- `BOT_TOKEN` - توكن البوت
- `ADMIN_ID` - آيدي الأدمن
- `TASK_REWARD` - مكافأة المهمة (5 ج)
- `GMAIL_TASK_REWARD` - مكافأة Gmail (10 ج)
- `REFERRAL_REWARD_EGP` - مكافأة الإحالة (4 ج)
- `REFERRAL_PER_EMAIL_REWARD_EGP` - مكافأة كل إيميل (1.75 ج)
- `USD_TO_EGP_RATE` - سعر الصرف (48 ج)

- مهمة إيميل عادية: 5 ج

- الحد الأدنى للسحب: 50 ج

- مكافأة أساسية: 4 ج (عند إكمال الصديق أول مهمة)

- المكافأة بالدولار تُحسب تلقائياً حسب سعر الصرف
